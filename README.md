# Nigerian Retail Sales & Customer Analytics (Power BI)

## Project Overview

This project is a Power BI report focused on Nigerian retail sales and customer analytics. It is designed to demonstrate the use of business intelligence tools to explore retail performance and communicate insights through interactive reporting.

The Power BI report file (`.pbix`) is included in this repository.

## Project Objectives

The project provides a practical portfolio example of how Power BI can be used to:
- Explore retail sales and customer data.
- Organise information into meaningful business views.
- Present performance indicators and trends.
- Support data-driven business discussions through visual reporting.

## Tool Used

## How to Open the Report

1. Download the `.pbix` file from this repository.
2. Install or open Microsoft Power BI Desktop.
3. Open Power BI Desktop.
4. Select **File → Open report**.
5. Choose the downloaded `.pbix` file.
6. Explore the report pages and interact with available filters and visuals.
